# 🇫🇮 Partitiivi ja Genetiivi — Грамматический тренажер A1

Бесплатный интерактивный веб-тренажер для отработки падежей **Genetiivi** и **Partitiivi** в финском языке (уровень A1). Приложение не требует регистрации, работает прямо в браузере и адаптировано для компьютеров и смартфонов. Доступна озвучка финских слов и фраз (только на Android)

👉 **[Открыть тренажер онлайн](https://max-roz.github.io/suomi-sanasto-A1/PartitiiviGenetiivi.html)**

---

## ✨ Возможности тренажера

* **100 практических предложений в контексте:** отработка падежных форм на реальных фразах с переводом на русский язык. Можно тренировать отдельно **Genetiivi**, **Partitiivi** или оба падежа вперемешку.
* **Встроенная шпаргалка по правилам:** отдельная вкладка с таблицами окончаний, правилами чередования согласных (KPT), списками глаголов процесса, местоимениями и исключениями.
* **Два режима практики:**
  * **Ввод:** самостоятельное написание нужной формы слова с клавиатуры (есть быстрая панель с финскими буквами `ä`, `ö`, `å` и кнопка грамматической подсказки).
  * **Тест:** выбор правильной формы из 4 похожих падежных вариантов с учетом чередования ступеней.
* **Озвучка предложений:** автоматическое и ручное прослушивание полных финских фраз для тренировки восприятия на слух.
* **Умный прогресс и настройки:** выбор длины раунда (10, 20 или все предложения), светлая и тёмная темы оформления, сохранение выученных фраз в браузере и работа над ошибками в конце раунда.

## 💻 Как запустить локально (без интернета)

Весь тренажер собран в один автономный HTML-файл, который можно сохранить на устройство и открывать офлайн:

1. Скачайте файл PartitiiviGenetiivi.html [прямая ссылка на скачивание] (https://github.com/max-roz/partitiivi-genetiivi/releases/download/V1.0/PartitiiviGenetiivi.html) (нажмите правой кнопкой мыши → «Сохранить ссылку как...») или скачайте [ZIP-архив репозитория](https://github.com/max-roz/partitiivi-genetiivi/archive/refs/heads/main.zip) и распакуйте его.
2. Откройте скачанный файл двойным кликом — он запустится в вашем браузере.

## 🛠 Технологии

Проект написан на чистом **HTML5**, **CSS3** и **Vanilla JavaScript** без сторонних фреймворков и серверной части. Для озвучивания текста используется Web Speech API и Google TTS.
